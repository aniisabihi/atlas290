# Decision log

Decisions taken during discovery and design live in the decision table of [docs/DESIGN.md](../DESIGN.md), each with its reason. From the first increment onward, every change to those decisions gets a dated file here, `NNNN-short-title.md`, stating context, decision, and consequences.

| Record                                                                         | What it covers                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [0001 — Decisions taken while building Plan 1](0001-plan-1-build-decisions.md) | The twenty-six rulings made during Plan 1's unattended execution. Five encode non-obvious Statistics Sweden data semantics (pre-existence zeros, the following-January boundary rule, per-cell perturbation, renumbered municipality codes, the enforced map-to-data join); the rest correct defects in the plan itself or close silent-failure paths. Two items are parked with reasons.                                                                                                                                                        |
| [0002 — How "places like this" is computed](0002-similarity-metric.md)         | The six decisions behind Plan 6's distance metric, each settled by measuring rather than arguing: all ten indicators equally weighted, a ten-year window fixed across the slider, a log transform for the four skewed indicators, missing cells reducing the dimensions rather than the value, five neighbours presented as a set because the fifth-to-sixth gap has a median of 0.032, and prose that tells a municipality's own story. Two consequences are recorded as limitations rather than fixed.                                         |
| [0003 — How the facts strip finds its own facts](0003-the-facts-engine.md)     | The six decisions behind Plan 7's facts engine. Five families with no score comparing them, because "how surprising" has no honest exchange rate across kinds of claim; leave-one-out for the family that uses Plan 6's neighbours, which closes a circularity the ordering decision did not anticipate; and a noise bound expressed in each indicator's own unit after three PEOPLE was briefly applied as three PERCENTAGE POINTS. Records that Plan 6's neighbours did not, on their own, solve the problem they were ordered first to solve. |
