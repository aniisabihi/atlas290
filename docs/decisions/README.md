# Decision log

Decisions taken during discovery and design live in the decision table of [docs/DESIGN.md](../DESIGN.md), each with its reason. From the first increment onward, every change to those decisions gets a dated file here, `NNNN-short-title.md`, stating context, decision, and consequences.

Five encode non-obvious Statistics Sweden data semantics (pre-existence zeros, the following-January boundary rule, per-cell perturbation, renumbered municipality codes, the enforced map-to-data join); the rest correct defects in the plan itself or close silent-failure paths. | [0002 — How "places like this" is computed](0002-similarity-metric.md)                        | The six decisions behind Plan 6's distance metric, each settled by measuring rather than arguing: all ten indicators equally weighted, a ten-year window fixed across the slider, a log transform for the four skewed indicators, missing cells reducing the dimensions rather than the value, five neighbours presented as a set because the fifth-to-sixth gap has a median of 0.032, and prose that tells a municipality's own story. Records that Plan 6's neighbours did not, on their own, solve the problem they were ordered first to solve.                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| [0004 — How the morph is built](0004-the-morph.md)                                            | The seven decisions behind Plan 8. Records that the morph has no unit-test coverage and cannot have any, because jsdom implements no path measurement.                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| [0005 — A page per municipality](0005-a-page-per-municipality.md)                             | The seven decisions behind Plan 9. | [0006 — The name](0006-the-name.md)                                                           | Atlas 290, chosen by the architect from a checked shortlist. | [0007 — The 404 that was not](0007-the-404-that-was-not.md)                                   | The first deploy revealed that production answered 200 with the root page for every unmatched path, because Cloudflare Pages treats a site with no top-level `404.html` as a single-page application. Corrects 0005 D6. The lesson is the reusable part: the test that asserted otherwise was checking our own simulation of Cloudflare against the assumption it was built from, so it could not have failed.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| [0008 — Response headers, and how these pages get found](0008-headers-and-discoverability.md) | The four decisions from the post-0006 review. A sitemap, because every page this site serves is a shell and a crawler that does not run JavaScript finds no links anywhere — the preview cards make a PASTED link show the place and do nothing to make an unpasted one findable. A Content Security Policy that hashes the root page's inline redirect rather than allowing inline script, served by the preview server so the browser suite exercises the real policy, and proven able to fail with a corrupted hash. Records that turning the policy on found a real `new Function` in the bundle (zod, feature-detecting JIT), and that the performance budget had been measuring a build nobody visits — SEO 91 for want of the canonical and hreflang the deploy writes and the budget did not. Also records why the budget stopped passing by luck: its floor of 80 sat inside the measured CI spread of 79-85, so it now takes a median of three runs and sits clear of it. |
