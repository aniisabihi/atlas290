| [0008 — Response headers, and how these pages get found](0008-headers-and-discoverability.md) | The four decisions from the post-0006 review. A sitemap, because every page this site serves is a shell and a crawler that does not run JavaScript finds no links anywhere — the preview cards make a PASTED link show the place and do nothing to make an unpasted one findable. A Content Security Policy that hashes the root page's inline redirect rather than allowing inline script, served by the preview server so the browser suite exercises the real policy, and proven able to fail with a corrupted hash. Records that turning the policy on found a real `new Function` in the bundle (zod, feature-detecting JIT), and that the performance budget had been measuring a build nobody visits — SEO 91 for want of the canonical and hreflang the deploy writes and the budget did not. | [0016 — The fifteen](0016-the-fifteen.md)                                                     | The eight decisions behind Plan 16, which takes the pantry from ten indicators to twenty-seven. Records that reading the tables changed six of the fifteen the design named: fertility has no sex total and summing one would not be a fertility rate, the labour tables have no age total so 20–64 is chosen and named, disposable income is already in fixed prices and is not adjusted again, the tax base loses its 2026 rather than putting one nominal figure at the end of an adjusted series, rent is per square metre so the id says so, and two units joined the contract because `count` rounds a fertility rate of 1.45 to 1. Seventeen indicators ship rather than fifteen, because the education gap cannot be checked unless the two splits it is built from are published too. Records two defects breadth found and one left deliberately unfixed: a single series ending in 2022 silently pulled every extreme fact back two years, two similarity guards read every indicator where they should read the core ten, and the country fact is now decided by the last tie-break tier for the first time. | [0015 — The old implementations go](0015-the-old-implementations-go.md)                       | The six decisions behind Plan 15, which closes what 0014 D7 deferred. The nine hand-written indicator implementations are deleted — 3,753 non-test lines down to 2,651, and the nine modules themselves halved — and the roughly 190 assertions against them were sorted rather than dropped: twenty-eight that were derived independently of the pipeline moved to the published pantry, thirty table-specific ones were retargeted at the declarations, and the rest went because the shared resolver now makes those claims generically. Records that the deletion found a live guard plan 14 had left behind in dead code, so post-secondary-education had been running without its codelist check; that this project's memory of two TAB1169 labels was wrong; and that reading OBSERVATION_STATUS from memory rather than from shared/pantry.ts turned four cells into plausible nonsense without erroring. | [0014 — Indicators become definitions](0014-indicators-become-definitions.md)                 | The seven decisions behind Plan 14. | [0013 — The pantry splits](0013-the-pantry-splits.md)                                         | The six decisions behind Plan 13. One file of 272,475 gzipped bytes became an index of 6,433 plus one file per indicator, so first paint costs about 35,301 rather than every cell of all ten indicators for a view that draws one — and the index barely grows with the count, because the 290 municipalities dominate it. | [0012 — Releases, and a changelog generated from commits](0012-releases-and-a-changelog.md)   | The seven decisions behind Plan 12. A version number that means one thing — MAJOR is a published URL that stopped working, and nothing else — because the URL grammar is the only promise this project makes outward. The monthly SCB refresh cuts no release: it already arrives as a reviewable pull request, and a version would otherwise claim to describe data it does not describe. Entries are generated by release-please from commit subjects, which only works if the subjects are conventional — checking the regex against every merged pull request found that **none of the nineteen** would have passed, including the squash-merged title carrying the whole of Plan 11, so a title check is part of the decision rather than an extra. Records plainly what the default `GITHUB_TOKEN` gives up: no CI on the release pull request.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
