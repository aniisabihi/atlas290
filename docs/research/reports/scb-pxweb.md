# Statistics Sweden (SCB) as a data source — fact-finding report

Date of research: 2026-09-10. Everything below was read from the cited pages/endpoints on that date. Items I could not confirm are marked **UNVERIFIED**.

## 1. PxWeb API: v1 vs v2

**Status.** SCB (SV page): "PxWebApi 2 släpptes oktober 2025 i Statistikdatabasen." and "PxWebApi 1 kommer fungera fram till årsskiftet 2026/2027." (https://www.scb.se/vara-tjanster/oppna-data/pxwebapi/). The v1 page repeats: "Under hösten 2025 ersattes PxWebApi v1 av PxWebApi v2. PxWebApi v1 kommer fungera till årsskiftet 2026/2027" (https://www.scb.se/vara-tjanster/oppna-data/pxwebapi/PxWebApi_v1/). So v1 is deprecated with a stated end-of-life around 31 Dec 2026. The English pages do not state the shutdown date.

**v1 base URL:** `https://api.scb.se/OV0104/v1/doris/sv/ssd/` (also `/en/`). Still fully live today (all folder and metadata endpoints I queried responded). Formats per the official v1 PDF (pxwebapi1.0_beskrivning_2024.pdf): "Format som stöds är • px • csv • csv2 • csv3 • json • xlsx • json-stat • json-stat2 • sdmx". Query is POST with a JSON body (`*` wildcard, `top`, `agg:`, `vs:` filters).

**v2 base URL(s):**
- `https://statistikdatabasen.scb.se/api/v2/` — confirmed live: `/config` and `/tables?query=...` both answered. This is the URL the Swagger UI (`https://statistikdatabasen.scb.se/api/v2/index.html`) and table search results point to (`.../api/v2/tables/TAB638/metadata?lang=sv`, `.../tables/TAB638/data?lang=sv&outputFormat=json-stat2`).
- `https://api.scb.se/OV0104/v2beta/api/v2/config` — also still answers (same apiVersion 2.3.2) but with `defaultDataFormat: "px"`; treat as the legacy beta host. Use `statistikdatabasen.scb.se`.

**v2 documentation:** user guide https://www.pxtools.net/PxWebApi/documentation/user-guide/ ; OpenAPI spec https://github.com/PxTools/PxApiSpecs/blob/master/PxAPI-2.yml ; Swagger UI https://statistikdatabasen.scb.se/api/v2/index.html ; source https://github.com/PxTools/PxWebApi ; v1→v2 query converter https://pxapiconverter.scb.se/ .

**v2 output formats (live `/config` at statistikdatabasen.scb.se):** `dataFormats: json-stat2, csv, px, xlsx, html, json-px`; `defaultDataFormat: json-stat2`. The generic PxWeb user guide also lists `parquet (beta)`, but it is **not** in SCB's config list, so assume parquet is unavailable at SCB.

**v2 query limits (live `/config`):** `maxDataCells: 150000`, `maxCallsPerTimeWindow: 30`, `timeWindow: 10`, `features: CORS enabled=True`. SCB's page wording: "Du kan ta ut hela eller delar av tabeller med en begränsning på 150 000 dataceller och göra max antal anrop med 30 stycken per 10 sekunder." and "Begränsningen ligger per IP-adress och kan därför gälla fler kollegor på samma arbetsplats." English: "You can extract entire or parts of tables with a limit of 150 000 data cells and make a maximum number of calls of 30 per 10 seconds." Exceeding gives HTTP 429; too many cells gives HTTP 400 "Too many cells selected". GET queries are limited to "approximately 2100 characters" of URL (user guide), so use POST for large selections. Selection expressions: `*`, `?`, `top(n)`, `bottom(n)`, `range(a,b)`, `from(a)`, `to(a)`; codelists via `codelist[var]=...`.

**v1 limits — inconsistent documentation:** the öppna-data page says "Du kan göra maximalt tio anrop per tio sekunder från en ip-adress." and "Du kan som mest hämta 100 000 värden per tabell. Felmeddelandet 'HTTP 403 Forbidden' markerar att maxvärdet är överskridet." The v1 PDF says "anroparen kan göra 10 anrop på ett tidsfönster på 10 sekunder (dessa värden kan komma att konfigureras i efterhand)". But the live v1 config (`https://api.scb.se/OV0104/v1/doris/sv/?config`) returns `{"maxValues":110000,"maxCells":150000,"maxCalls":30,"timeWindow":10,"CORS":true}` — i.e. the real limits are currently the same as v2.

**Authentication / cost:** no API key or login is mentioned anywhere in the API pages or the config; "Du kan använda SCB:s öppna data utan kostnad." (öppna data page). "SCB:s API tillhandahålls i befintligt skick." (no SLA).

## 2. License of SCB open data

Terms page (https://www.scb.se/om-scb/om-scb.se-och-anvandningsvillkor): "Statistik och geodata som SCB tillgängliggör som öppna data i statistikdatabasen och i vår geodataplattform har licensen Creative commons 0 1.0 Universal, CC0." and "För allt övrigt material på SCB:s webbplats används licensen Creative Commons Erkännande 4.0 Internationell (CC BY)." Note the same page says that for statistics taken from scb.se (the website, CC BY) "ska dock som källa alltid SCB anges" — that applies to web-page material, not the CC0 database/API.

Öppna data page (https://www.scb.se/vara-tjanster/oppna-data/): "Vi använder licensen CC0 för dessa data, vilket innebär att du får använda och sprida..." with recommended attribution "Källa: SCB" / "Source: Statistics Sweden". English page: "You may use and disseminate or provide such data without any requirement to state the source." The v2 `/config` also carries `license: https://creativecommons.org/share-your-work/public-domain/cc0/`. Wikimedia Sverige reports the switch to CC0 took effect 1 July 2021 (decision 25 May 2021).

## 5. DeSO and RegSO

- DeSO: 2018 version 5,984 areas (REGINA); revised **DeSO 2025** has 6,160 areas, population mostly "mellan 700 och 3 000". RegSO: "RegSO delar in Sverige i 3 363 områden" (both 2020 and 2025 versions), population "i de flesta fall … mellan 650 och 23 000"; "RegSO är ett aggregat av Demografiska statistikområden (DeSO)".
- Statistics published at DeSO/RegSO (SSD folders "Regional statistik på lägre nivå än kommun"): population `BE0101Y/FolkmDesoAldKon` (age, sex) 2010–2025, by civilstånd/födelseregion/medborgarskap/bakgrund 2010–2025, households `HushallDesoTyp` 2011–2025; income `HE0110I/Tab1–4InkDesoRegso` 2011–2024 (income classes, ekonomisk standard, low/high economic standard); education `UF0506D` (2015–2025 per DeSO page); labour market `AM0210G/ArRegDesoStatusN` etc. 2020–2024 (+ RAMS `AM0207I` 2018–2021); housing stock `BO0104T01N2` (DeSO/RegSO 2025, 2024–2025) and `BO0104T10N` (DeSO 2018/RegSO 2020, 2015–2023); cars `TK1001Z`; land area and buildings (Miljö); socioeconomic index (integration) 2011–.
- Boundaries: GeoServer WFS/WMS at `https://geodata.scb.se/geoserver/stat/` with layers `stat:DeSO_2018`, `stat:DeSO_2025`, `stat:RegSO_2020`, `stat:RegSO_2025` (also tätorter, småorter, 1 km grid, 1 km population grid 2015–2025). DefaultSRS **EPSG:3006 (SWEREF 99 TM)**. GetFeature output formats include GeoPackage, SHAPE-ZIP, GeoJSON, CSV, KML, GML. SCB's direct download: `https://geodata.scb.se/geoserver/stat/wfs?service=WFS&REQUEST=GetFeature&version=1.1.0&TYPENAMES=stat:DeSO_2025&outputFormat=geopackage` (same pattern for RegSO_2025). Attributes: "en polygon för varje DeSO med information om bland annat län och kommun." Correspondence files DeSO2025–RegSO2025 (xlsx) and historical-change files are linked from the RegSO geodata page. License: covered by the CC0 sentence in §2 ("…i vår geodataplattform har licensen … CC0"); the DeSO/RegSO pages themselves only link to "Så får du använda SCB:s öppna data".

## 7. Municipality code changes since ~1990 and SCB's tools

SCB's "Ändringar i kommunindelningen efter 1974" (kommunandringar_20230829.pdf) lists, verbatim: 1992-01-01 "Ur 0480 Nyköpings kommun har utbrutits två nya kommuner benämnda 0461 Gnesta och 0488 Trosa."; 1995-01-01 "Ur 1583 Borås kommun har utbrutits en kommun benämnd 1535 Bollebygd." and "Ur 1880 Örebro kommun har utbrutits en kommun benämnd 1814 Lekeberg."; 1999-01-01 "Ur 0181 Södertälje kommun har utbrutits en kommun benämnd 0140 Nykvarn."; 2003-01-01 "Ur 0380 Uppsala kommun har utbrutits en kommun benämnd 0330 Knivsta." (290 kommuner since); 2011-01-01 Lidingö extended with Storholmen from Vaxholm. Code/name changes: "1997-01-01 samt 1998-01-01 skedde kodändringar av kommuner till följd av länssammanslagningar" (Skåne 1997, Västra Götaland 1998 — all kommun codes in those counties changed; separate xlsx keys are linked); "2007-01-01 övergick Heby kommun, tidigare tillhörande Västmanlands län, till Uppsala län och fick då koden 0331."; Upplands Väsby renamed 2002; Malung → Malung-Sälen 2008.

Tools: (a) "Kommunändringar 1974-idag" PDF + xlsx key `knkodnyckel.xls` and "Kommuner med kopplingar till andra indelningar" `knkopplingar_2026.xlsx` (https://www.scb.se/hitta-statistik/regional-statistik-och-kartor/regionala-indelningar/lan-och-kommuner/); (b) **REGINA** (https://regina.scb.se/indelningsandringar) — code lists and change records (old/new code, name, date, type) for län/kommun/församling/distrikt/DeSO/RegSO from 1952, exported as tab-separated .txt or .xlsx; (c) inside the tables: current codes are used throughout and footnotes document breaks, e.g. TAB638: "Folkmängd år 1968–1982 redovisas enligt regional indelning 1983-01-01.", "Ny regional indelning fr.o.m. 2003-01-01. Delar av Uppsala kommun (0380) bildar en ny kommun benämnd Knivsta kommun (0330).", "Fr o m 2007-01-01 överförs Heby kommun från Västmanlands län till Uppsala län." Post-1983 splits are **not** back-cast: expect no Knivsta values before 2003 etc. (inferred from the notes; exact cell behaviour UNVERIFIED — check for empty cells vs. parent-inclusive values).

## 8. Caveats: suppression, revisions, timing

- **Cell Key Method (CKM) noise.** "en liten och kontrollerad slumpmässig osäkerhet automatiskt tillförs statistikvärdena"; frequencies "justeras med ett litet negativt eller positivt heltal, eller lämnas oförändrade" (−3…+3); "de redovisade totalerna inte alltid är lika med summan av deras redovisade delar". Rollout: BAS May 2022; Census 2021; income & taxes ongoing; integration statistics and hushållens boende April 2026; **befolkningsstatistiken spring 2026** (i.e. reference year 2025 onward — hence the "…CKM" tables starting 2025); yrkesregistret planned 2027; education under review 2026. SCB: existing tables are split into old and new versions, so long series require "uttag från två olika tabeller", but "Alla gamla API-länkar i SSD kommer att fungera även framöver". Tables with CKM carry a footnote. (Sources: /dokumentation/statistikomraden-under-forandring/utveckling-av-rojandeskyddet/ and FAQ-CKM.) I found no explicit DeSO-specific suppression thresholds on the DeSO/RegSO instruction pages (searched; none quoted) — **UNVERIFIED** beyond the general CKM regime.
- **Publication lag (from table `updated` stamps and SCB news):** population 31 Dec 2025 published 2026-02-24 (municipal totals/age groups), extended tables 2026-03-24; income 2024 → 2026-01-20 (~13 months); education 2025 → 2026-04-27; BAS annual 2024 → 2025-11-28; dwelling stock 2025 → 2026-04-17; completed dwellings 2025 → 2026-05-11; property prices 2025 → 2026-06-05; rents 2025 → 2025-10-03; cars 2025 → 2026-02-12; tax rates for 2026 → 2025-12-15. Monthly population is published ~5 weeks after month end (2026M07 on 2026-09-07).
- **Series breaks:** RAMS ended with 2021 ("ny tidsserie" 2019–2021), BAS starts 2020 with different definitions; housing register-based stock tables start 2013 (T04 goes back to 1990); DeSO tables switch from DeSO 2018/RegSO 2020 to the 2025 versions (separate tables). Election tables end at 2022.

## Risks for a zero-cost static app

1. **v1 sunset end-2026** — build on `https://statistikdatabasen.scb.se/api/v2/` from day one; v1 examples online (pyscbwrapper, most blog posts) will stop working.
2. **150,000 cells/query and 30 calls/10 s per IP** — a full population cube (290 × 102 ages × 2 × 57 years ≈ 3.4 M cells) needs ~25+ chunked calls with throttling. Do this at build time (e.g. a scheduled CI job) and ship pre-aggregated static JSON; do not fan out dozens of live API calls per page view.
3. **CORS is enabled** on both v1 and v2, so light live calls from the browser are technically possible; but "tillhandahålls i befintligt skick" (no SLA) argues for static snapshots plus optional live refresh.
4. **CKM noise and table splits** from reference year 2025: totals ≠ sum of parts; you must merge "–2024" and "2025– CKM" tables and label small values as perturbed.
5. **GET URL cap (~2,100 chars)** — use POST for wide selections; use codelists (`agg_Ålder5år`, `vs_RegionKommun07`) to cut cell counts.
6. **Boundary data** is CC0 but shipped as zipped Shapefile/MapInfo (kommun/län) or GeoPackage/GeoJSON via WFS (DeSO/RegSO), all in EPSG:3006 — convert to (Topo)GeoJSON WGS84 at build time; SCB says the kommun files are simplified for thematic maps only.
7. **Code changes** (Skåne 1997, Västra Götaland 1998, Knivsta 2003, Heby 2007) mean older external data keyed on old codes must be re-mapped; SCB tables already use current codes but have gaps before splits.
8. **Timing gaps**: income lags ~13 months, RAMS commuting stops at 2021, election data stops at 2022 — set expectations in the UI.
9. **Documentation inconsistency**: published v1 limits (10 calls/10 s, 100,000 values) differ from the live config (30/10 s, 110,000 values, 150,000 cells); rely on `/config` at runtime rather than hard-coding.
